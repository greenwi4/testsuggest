The Entity Verification API (EVA) authenticates users based on a specific underlying authentication method. You can access the API and its functionalities using an API key.

1. Get an API key.
   API key access is managed by Moody's. You can get your API key directly from your point of contact at Moody's.

<Callout icon="ℹ️" theme="info">
  You must have a contract with Moody's for a commercial API package to access an API key.
</Callout>

2. Regenerate an API key.
   Your API key is generated for long-term use and does not expire in a short window. However, it can be regenerated manually upon request.

<Callout icon="👍" theme="okay">
  To regenerate an API key, raise a request with your point of contact at Moody's.
</Callout>
