Users who have created a Wero User Profile can access the profile management interface from the mobile banking app or the standalone app. Alternatively, you can access the profile through Wero's homepage.

## Access through an app

| **Step** | **Description**                                                                                                                                                                                                                                                                                                                        | **Illustration**                                                                                                                                              |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1**    | If you have linked your Wero wallet with your Wero User Profile, the mobile banking app and the standalone app display a call to action that allows you to manage your profile. Following this call to action redirects you to the Wero profile management interface. <br /><br />The app performs the authorisation code flow.        | ![Screenshot: manage profile CTA bankapp](https://files.readme.io/a024a6fd9c2a0c22956d5eb97a9ca4176bb6b3ddb12a59e357c41c528b029554-Banko___mange_profile.png) |
| **2**    | After successful passkey authentication, you're redirected to the profile management interface, where you can: <br /><br /><ul><li>Add and remove linked bank accounts.</li><li>Add, edit, and remove stored shipping addresses.</li><li>Add and remove registered passkeys for authentication.</li><li>Delete your profile.</li></ul> | ![Screenshot: manage profile](https://files.readme.io/eaa5bd9eb9b95f087a807549de2dcfe56f7fd407807800f8311573251c72585b-Profile_bank_account_1.png)            |
