> <<glossary:PCI>> Scope
> These tokens can be securely utilized or stored on the merchant's server, significantly reducing the vendor's or merchant's <<glossary:PCI>> footprint.
> 
> The merchant/developer must use `data.meta.savePaymentOption` to determine if they are allowed to store the token reference in their database as saved cards. See [Using the SDK | Credit/Debit Card](ref:using-the-sdk#creditdebit-card).
> 
> For more information, refer to [PayConex™ API Introduction](ref:payconex-introduction) and [PayConex™ and ShieldConex®](ref:payconex-and-shieldconex).
