| **Parameter** | **Description** | **Type** | **Required** | **Possible Values** |
| --- | --- | --- | --- | --- |
| advertiserId | The ID of the advertiser | integer | Y | Unique numeric identifier |
| startDate | The first day to be considered in the performance report snapshot. It cannot be the current date.<br>**_Note:_** _The reports encompass data starting from midnight (00:00:00 hrs ET) on this particular date._ | date | Y | Date should be in format: `yyyy-MM-dd` |
| endDate | The last day to be considered in the performance report snapshot. It cannot be the current date.<br>**_Note:_** _The reports encompass data until the end of the day (23:59:59 hrs ET) for this particular date. If report data is not available for the requested end date, the request will fail, and the response will contain the endDate until which the performance report is available._ | date | Y | Date should be in format: `yyyy-MM-dd` |
| attributionWindow | Window for attribution.<br>**_Note:_** _attributionWindow is applicable only when reportType = sku._ | string | Optional and applicable only for `sku` report | **Allowed Values:** `days14` — report will include 14-day attribution columns; `days30` — report will include 30-day attribution columns |
| salesChannel | Sales channel for the transaction.<br>**_Note:_** _salesChannel is applicable only when reportType = sku._ | string | Optional and applicable only for `sku` report | If specified, the metrics applicable for the specified sales channel are returned.<br>**Allowed Values:** `stores`, `online`, `acc`<br>`stores` — only metrics prefixed with storeAttributed are returned; `online` — only metrics prefixed with pickupAttributed, deliveryAttributed are returned; `acc` — only metrics prefixed with accAttributed are returned |
| itemsetType | Type of item set.<br>**_Note:_** _itemsetType is applicable only when reportType = sku._ | string | Optional and applicable only for `sku` report | If specified, the metrics applicable for the specified itemsetType are returned.<br>**Allowed Values:** `halo`, `featured`, `total`<br>`halo` — only metrics that have "Halo" in them; `featured` — only metrics that have "Featured" in them; `total` — only metrics that have "Halo" or "Featured" in them |
| reportType | Type of report to be retrieved | string | Y | **Types of Report:** `campaign`, `lineItem`, `tactic`, `sku`, `bid`, `newBuyer`, `creative` |
| reportMetrics | Choose the metrics type for your snapshot.<br>**_Note:_** _If you omit this parameter in your request, you will receive all the metrics that are relevant to the selected report type._ | string | N | Please refer to the table [**Definition of Various Parameters Generated Across the Snapshot Reports**](/advertising-partners/docs/definition-of-various-parameters-generated-across-the-snapshot-reports) for detailed information on report metrics. |
| scope | Controls the aggregation level at which report metrics are returned. | string | N | **Possible values:** `CAMPAIGN`, `CAMPAIGN_GROUP`<br>When `reportType` is `campaign`, `lineItem`, `sku`, or `newBuyer`, the default `scope` = `CAMPAIGN`.<br>When `reportType` is `creative`, `tactic`, or `bid`, `scope` = `CAMPAIGN_GROUP` is not supported and returns an error.<br>When `scope` = `CAMPAIGN_GROUP`, the `campaign`, `lineItem`, `sku`, and `newBuyer` reports include 2 additional fields: `campaignGroupId` and `campaignGroupName`.<br>If `scope` isn't defined in the request, it defaults to `CAMPAIGN`. |
